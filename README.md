# ماركت الكينج — موقع متجر رقمي

واجهة متجر عربية RTL متجاوبة مع الموبايل، بهوية أسود وأحمر.

## تشغيل محليًا
يتطلب Node.js:
```bash
npm install
npm run dev
```

## النشر مجانًا على Vercel من أندرويد
1. فك ضغط `market-king-website.zip` على هاتفك.
2. أنشئ مستودعًا جديدًا على GitHub من المتصفح.
3. ارفع ملفات المشروع مع الحفاظ على المسارات: `index.html` و`package.json` ومجلد `src`.
4. افتح Vercel وسجّل الدخول باستخدام GitHub.
5. اختر **Add New → Project** ثم استورد المستودع.
6. اترك Framework Preset على **Vite** (أو Other إذا لم يُكتشف تلقائيًا)، وBuild Command هو `npm run build`، وOutput Directory هو `dist`.
7. اضغط **Deploy**. سيعطيك Vercel رابطًا عامًا للموقع.

## تخصيص المنتجات
عدّل مصفوفة `products` في `src/main.js` لتغيير أسماء المنتجات ووصفها وأسعارها. الأسعار الحالية أمثلة تجريبية وليست أسعارًا مؤكدة.
رابط التواصل مضبوط على `https://t.me/z_b_w_1`.

## ملاحظات مهمة
- السلة تعمل داخل المتصفح وترسل تفاصيل الطلب إلى تليجرام عبر رابط رسالة.
- هذا نموذج واجهة أمامية: لا توجد قاعدة بيانات أو لوحة تحكم أو بوابة دفع فعلية.
- زر تليجرام يفتح صفحة الحساب/المحادثة؛ بعض عملاء تليجرام قد لا يملؤون نص الرسالة تلقائيًا، لذا يمكن نسخ تفاصيل الطلب يدويًا إذا لزم الأمر.
- تأكد من الأسعار والتوفر وحقوق بيع كل خدمة قبل نشر المتجر.
